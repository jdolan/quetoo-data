Model Name              : Gammy
Origin                  : id Software, Quake III: Team Arena (2000)

Model description       :

Gammy is a member of "The Fallen," one of the five bot clans
introduced in Quake III: Team Arena, alongside Gaunt. These were
originally shipped as non-selectable AI opponent skins bundled with
Team Arena, not as standalone downloadable player models.

This model file was later extracted from the Team Arena assets and
repackaged by a third party as a selectable multiplayer skin (widely
circulated online as part of a "Quake 3 Clan Model Pack"), without any
accompanying readme or additional license terms.
