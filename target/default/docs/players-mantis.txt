Author's notes	:
This model is my first game model. I've done a little 3d modelling and 2d work prior to this, butalmost no low-poly work. The model is insipired by the alien in Predator (one of my faves). I think the model screams out for some custom shader work, but I didn't get a chance. It was my first time using the Unwrap UVW modifier in 3DSMax so I'm not all that happy with the fuzziness of the body's skin. But I think I got the point across. 
As for the animations, I wanted to do something custom for this guy , but a decent model and maps were a higher priority for me so I just did some Id .bip modifying. I'm learning one step at a time.
 Please let me know what you think.
